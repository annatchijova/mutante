Contribution Guidelines
1. How to Contribute
We welcome contributions to MUTANTE! Whether you are fixing a bug, adding a new adversarial mutation strategy, or improving the VIGÍA detection logic, your help is appreciated.

Fork the repository and create your branch from main.

Add your feature/fix following the existing project structure (agent_mutante/engine/).

Ensure code quality: Run existing tests in test_full_pipeline.py to ensure no regressions.

Submit a Pull Request with a clear description of the changes.

2. Reporting Issues
Found a bug? Open an issue and provide:

A clear description of the behavior.

Steps to reproduce (e.g., using a specific behavior from harmbench_behaviors.csv).

Logs or stack traces if available.
